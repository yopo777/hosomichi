# hosomichi 🚲 細道ルートナビ

大通りをできるだけ避けて、細い道を通る自転車ルートを自動で作って、そのままナビできます。
ブラウザだけで動きます（インストール・登録不要）。スマホはホーム画面に追加するとアプリのように使えます。

👉 https://yopo777.github.io/hosomichi/

## できること
### ルートを作る
- 出発地・到着地を入れて Enter（駅名・住所・GoogleマップのURL・地図タップ）。出発が空なら現在地から
- おまかせ設定：近道 / おすすめ / 細道こだわり
- ⚙ 細かく設定
  - 道の種類ごとの避けぐあい（住宅街・一般道・県道・国道・歩道・農道など、×1〜通らない）
  - 階段（通らない / 自転車スロープ付きだけ / 通る）、歩道橋・地下道、砂利・土の道
  - 4車線以上の道は信号のある所で渡る、2車線の道は横断歩道で渡る、などの横断ルール
  - 地図データを取る広さ（せまい＝早い / ふつう / ひろい）
- 歩行者・自転車用の踏切も使う
- 地図に 🟢信号で横断 / 🔵横断歩道で横断 / 🔴ルールどおりに渡れなかった場所 を表示

### ナビ
- ◎ で現在地ナビ（地図が追従・残り距離・ルートから外れたら警告・画面スリープ防止）
- ナビ中は地図がずれない（拡大・縮小だけ）。もう一度 ◎ で解除
- 🧭 で 北が上 / 進む向きが上（ヘディングアップ）
- 🗺 で地図の種類（淡色・標準・写真）

### 保存・共有
- 💾 ルートを端末に保存して、あとで一覧から開ける（前回のルートは自動で表示）
- 🔗 ルートをURLで共有（出発地・到着地のまわりを隠せる）
- ⬇ GPX ダウンロード
- 一度取った道路データは端末に30日保存（2回目からは速い）

## 使い方のコツ
- 初めての場所は道路データの取得に時間がかかります。急ぐときは「地図の広さ」を「せまい」に
- 「ルートが見つからない」ときは「地図の広さ」を広げてみてください（川や線路で大回りが必要な場所など）
- 自宅から出発したルートを共有するときは「出発地のまわりを隠す」を使ってください

## データ
- 地図：[国土地理院](https://maps.gsi.go.jp/development/ichiran.html)
- 道路データ：© [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors（Overpass API）
- 住所検索：国土地理院 / Nominatim

ルートは OpenStreetMap のデータから自動で作っています。実際の道路状況・交通ルールを確認して、安全に走ってください。
