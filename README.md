# hosomichi 🚲 細道ルートメーカー

大通りをできるだけ避けて、細い道を通る自転車ルートを自動で作ります。
ブラウザだけで動きます（インストール・登録不要）。

👉 https://yopo777.github.io/hosomichi/

## できること
- 出発地・到着地（駅名・住所・GoogleマップのURL・地図タップ）から細道ルートを自動作成
- 細道へのこだわり度を 1〜10 で調整
- 4車線以上の広い道は信号のある場所で横断
- 階段（スロープなし）・砂利道を避ける／歩行者・自転車用踏切は使う
- 作ったルートの上に現在地を表示（地図が追従・残り距離・ルート外れ警告・画面スリープ防止）
- ルートをURLで共有（出発地・到着地のまわりを隠す設定つき）
- GPX ダウンロード

## データ
- 地図：[国土地理院](https://maps.gsi.go.jp/development/ichiran.html)
- 道路データ：© [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors（Overpass API）
- 住所検索：国土地理院 / Nominatim

ルートは OpenStreetMap のデータから自動で作っています。実際の道路状況・交通ルールを確認して、安全に走ってください。
