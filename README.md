# 🚲 細道ルートナビ

大通りをさけて、細い道を通る自転車ルートを作ってナビします。ブラウザだけで動きます（登録・インストール不要）。

👉 **https://yopo777.github.io/hosomichi/**

- 位置情報・家・走った記録は**その端末の中だけ**。どこにも送りません。作者は他人の位置情報に関心ありません
- 開いただけでは位置情報は使いません（◎を押したときだけ）

## 使いかた
1. **🚲 ルート**：出発（空なら現在地）・経由・到着を入れて「ルートを作る」
2. **🏁 クエスト**：🎯 ミッション（寄り道・ランチ・おやつの場所をおまかせで選んで1周）／🏆 チャレンジ（駅・神社などをぜんぶ回る）
3. **◎** でナビ。曲がる所・ルートから外れた所は声で案内。外れたら「↩ ルートにもどる」
4. 走ったら **📣 SNS**：地図画像と投稿文を作ります（家のまわり・時刻・距離は出しません）

## べんり
- **住所をタップ**：北が上でルート全体
- **⚙ 設定**：道の好み／ナビ（音声・まわりだけ表示・画面を暗く）／地図／その他
- **🧪 ためし走行**：GPSなしでルートの上を自動で走る（テスト用）
- 地図を長おし：出発・到着・🏠家・🧪ためしの現在地・🚫通れない

## データ
- 道路・駅・スポット：© OpenStreetMap contributors（ODbL）。関東の配布データは [hosomichi-data](https://github.com/yopo777/hosomichi-data)
- 地図：CyclOSM / 国土地理院。標高・住所：国土地理院

## 開発
`src/app.html`（画面）＋`src/router.js`（ルート計算）を `python src/build.py` で1枚の `index.html` にします。データは `tools/make_pack.py`・`tools/make_quests.py`（Windowsで止められたら `pip install "osmium<4.3"`）。

自動で作ったルートです。実際の標識・交通ルールを守って、安全に走ってください。
