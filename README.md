# 🚲 細道ルートナビ

大通りをさけて、細い道を通る自転車ルートを作ってナビします。ブラウザだけで動きます（登録・インストール不要）。

👉 **https://yopo777.github.io/hosomichi/**

> ⚠ 自宅などが入ったルートを共有するのは自分だけにしてね。SNSなどに貼るときは注意！

## 使いかた
1. Chrome か Safari で開く（スマホは「ホーム画面に追加」がおすすめ）
2. 「到着」に駅名・住所などを入れて Enter（出発が空なら現在地から・経由地は1つまで入れられます）
3. ルート1〜3から選んで、**◎** を押して走る

関東一円は道路データを配っているので、数秒でルートができます（150kmまで。関東の外は30kmまで）。

## ボタン
- **🔍** 地名・駅名で地図を動かす（そのまま出発・経由・到着にできます）
- **◎** ナビ（現在地についていく）　**🧭** 北が上 / 進む向きが上　**🎨** ルートの色（赤 / 道の種類 / 坂）
- **💾 保存**　**🔗 共有URL・QR**　**⬇ GPX**　**■ 止める**　**▶ 続きを計算**
- 地図の丸い印の意味は、左下に出ます。地図が少し暗い所は、道路データのダウンロードが必要な所です

## タブ
- **⚙ 設定**：背景の地図（CyclOSM / 国土地理院）、道の種類ごとの避けぐあい、曲がる回数、道の渡りかた、一方通行、歩道のある道、旧街道、階段・砂利など
- **🗺 データ**：道路データをまとめて入れる・書き出す・読みこむ（パソコン向け。スマホでは通信量に注意）
- **📜 ログ**：計算中にしていることが全部見られます

## うまくいかないとき
- **場所がちがう**：駅は「JR日光駅」「東武日光駅」のように会社名をつけると確実。GoogleマップのURLを貼るのもおすすめ
- **ルートが見つからない**：⚙ 設定の「地図データを取る広さ」を広げる
- **関東の外で遅い**：道路データを OpenStreetMap のサーバーから取るので時間がかかります
- **新しい版にならない**：画面上に「🆕 新しい版があるよ」が出たら押す
- **iPhone**：位置情報は「設定 → プライバシー → 位置情報サービス → Safari」で許可。全画面はホーム画面に追加して使う

## データ
- 道路・駅：© OpenStreetMap contributors（ODbL）。関東の配布データは [hosomichi-data](https://github.com/yopo777/hosomichi-data)
- 地図：CyclOSM / 国土地理院（地理院タイル）。標高：国土地理院
- 検索：国土地理院 / Nominatim / Photon
